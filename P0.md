## Comportamiento de esta entrega

El sitio muestra el catálogo como ejemplo, conserva el carrito para revisión y ofrece consultas al WhatsApp confirmado. No acepta pedidos web mientras NEXT_PUBLIC_COMMERCE_READY sea false. La API también bloquea la creación de pedidos para evitar importes ficticios. El acceso y almacenamiento de pedidos existentes no se modifica.

Se retiraron la historia y ubicación física heredadas, testimonios sin respaldo, enlaces de otra marca, promesas de tarjeta, entrega exprés, cambios gratuitos y tiempos de respuesta no confirmados. La página de contacto usa enlaces directos, sin un formulario que parezca enviar mensajes. Los eventos se presentan como inspiración, no como trabajos realizados.

Mientras la tienda esté en preparación, no se publican ofertas de producto en datos estructurados, el sitemap está vacío y se solicita no indexar. Esto no sustituye una restricción de acceso: la vista previa sigue siendo accesible.
